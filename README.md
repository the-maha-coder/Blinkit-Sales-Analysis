# 🛒 Blinkit Sales Analysis Dashboard

## 📌 Project Overview

This project analyzes Blinkit's sales data using Power BI.
The dashboard provides insights into sales performance,
product categories, outlet characteristics, and customer ratings.

## 🎯 Project Objectives

- Analyze overall sales performance.
- Identify sales trends across outlet establishment years.
- Compare sales across different item categories.
- Understand sales distribution by fat content.
- Analyze outlet size and location performance.
- Compare outlet types using key performance indicators.

## 🛠️ Tools and Technologies

- Power BI
- Power Query

## 📊 Key Performance Indicators (KPIs)

- Total Sales
- Average Sales
- Number of Items
- Average Rating

## 📈 Dashboard Features

- Interactive filters for outlet location type, outlet size,
  and outlet type.
- Sales analysis by item category.
- Outlet establishment year analysis.
- Outlet size and location comparisons.
- Fat content analysis.
- Outlet type performance table.

## 💡 Business Questions

1. Which item categories generate the highest sales?
2. How do sales vary by outlet type?
3. Which outlet location tier contributes the most sales?
4. How are sales distributed across outlet sizes?
5. How does sales performance vary by item fat content?
